(`src/mu/best_configs.py`); mean over seeds (3-3 seeds per row). Generated by `scripts/analyze_quant_best.py`.

## Observations and conclusions (added 2026-11-01; full discussion `records/results/evaluation.md` section 6)
Figures (`scripts/plot_quant_best.py`): `records/figures/fig_quant_best_forget_vs_bits.png`, `fig_quant_best_int4_delta.png`,
`fig_quant_best_avg_gap.png`, `fig_quant_best_mechanism.png`; margin diagnostic `fig_quant_margin_diag.png`; t-SNE fp32 vs INT4
`fig_embed_quant_S1c0_int4.png`.
- No method regains forgotten knowledge at any bit width (largest forget-acc increase +0.42, INT8, Boundary S2-10). INT8 / INT6 change
  forget acc by at most 1.46 points.
- S1: INT4 changes forget acc by -0.19 to +0.01 (all <= 2.4%), test acc by -0.82 to -0.20; the forgetting is stable.
- S2: INT4 lowers forget acc for every method (Gradient Ascent -3.3 to -6.3, GA + Descent -3.6 to -4.8, Teacher-Student -1.2 to -3.2,
  Random Relabeling -0.1 to -1.4, Boundary Relabeling -7.2 to -8.1; Retrain -0.2 to -1.0), together with retain (-0.2 to -2.1) and test
  acc (-0.4 to -1.8): non-selective degradation. avg_gap improves only where the fp32 model under-forgets (Teacher-Student, Gradient
  Ascent on S2-10) and worsens elsewhere.
- The INT4 drop is largest for the smallest updates (Gradient Ascent, Boundary C0: 0.001-0.006 INT4 steps) and smallest for Random
  Relabeling (0.48-0.86 steps) and Retrain; `quant_margin_diag.md` shows why: these methods leave many forget-class samples correct but
  low-margin, and INT4 flips them.
- Note on the "share Q(theta_u)=Q(theta_o)" column: `scripts/eval_quant.py` compares de-quantised values (integer code x per-channel
  scale), so a weight counts as different whenever its channel's max |w| changed, even if its integer code is unchanged.
- Conclusion: H1 (quantization restores forgotten knowledge) rejected; H2 (quantization helps forgetting) only as non-selective accuracy
  loss. INT8 is safe for all unlearned models, INT4 is not for methods that leave low-margin forget-class samples.
